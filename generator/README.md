# Deterministic synthetic-data generator

This generator produces source-contract v1 data for repeatable development and
test evidence. A versioned profile is the complete source of variability: the
implementation does not read the clock, create random UUIDs, or use the host
locale or platform line separator.

The committed `smoke-v1` profile creates a small, clean reconciliation bundle:

| Measure | Expected value |
| --- | ---: |
| Seed | `20260731` |
| Suppliers | 10 |
| Invoices | 100 |
| Invoice lines | 203 |
| Ledger entries | 100 |
| Invoice net | SGD 142,125.16 |
| Invoice tax | SGD 12,791.26 |
| Invoice gross / ledger debit | SGD 154,916.42 |

Each invoice has one to three lines and one matching ledger entry. Identifiers
and supplier registration values are visibly synthetic. The 9% tax rate and
`HALF_UP` rounding are fixture-generation rules only; they are not an
authoritative Singapore tax engine or a claim about production tax treatment.

## Generate the smoke bundle

From the repository root on Windows PowerShell with Java 21 installed:

```powershell
cd backend
.\mvnw.cmd --batch-mode --no-transfer-progress compile `
  org.codehaus.mojo:exec-maven-plugin:3.6.3:java `
  "-Dexec.mainClass=io.github.charlescrtech.invoicenow.generator.SyntheticDatasetCli" `
  "-Dexec.args=--profile=../generator/profiles/smoke-v1.json --output=../data/smoke/v1"
```

On a Unix-like shell, use `./mvnw` and line-continuation backslashes. The CLI
accepts exactly one `--profile` path and one `--output` directory. Invalid or
out-of-bound profiles fail before generation. Existing named output artifacts
are replaced atomically where the filesystem supports atomic moves.

The committed bundle is byte-for-byte reproducible at [data/smoke/v1](../data/smoke/v1):

| Artifact | SHA-256 |
| --- | --- |
| `dataset.json` | `a280df842bc0bc20f962651f4869c648b61fe2a6b18e613660360ece6ccec756` |
| `suppliers.csv` | `3bc3f09a22fec76ab2183dc18a35a884bb42aa709402331b9a73277d7a47647d` |
| `invoices.csv` | `91fd08394e0f2836ec881622b35e2e55d0cfc7512aa38ec723d42a83a72f3a30` |
| `ledger_entries.csv` | `3e9933cad4995ed2082e9c8ee8887f25669bab388cf1b011e7ba1db0875cb4ce` |

Generated files are UTF-8 without a byte-order mark and use LF line endings.
JSON and CSV carry the same contract version and dataset identifier. Artifact
hashes describe the generated bytes; source-payload hashes needed during import
remain the responsibility of the future import pipeline.

## Scope and extension points

This first profile intentionally contains only clean records. Scenario
manifests, exception injection, and a test-only expected-results oracle belong
to `IRW-106`. Demo and performance profiles belong to `IRW-107`. InvoiceNow XML,
production tax-policy decisions, import behavior, and reconciliation controls
are outside this generator's current contract.

The executable specification is
`SyntheticDatasetGeneratorTest`: it proves same-seed byte identity, seed
sensitivity, counts, references, financial reconciliation, encoding, profile
bounds, safe writes, and exact agreement with the committed smoke bundle.
